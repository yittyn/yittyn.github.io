### Mapping the Modern Dev Cycle

Up until now, my developer workflow has been straightforward: sketch out a feature spec, refine it with AI, write the code, and iteratively prompt the model to modify the code while updating the spec in parallel. 

But to optimize my end-to-end dev cycle, I spent today unpacking the broader vocabulary and methodology of modern software engineering:
* **Vibe Design:** Early, rapid UI ideation and prototyping before committing to code.
* **SDD / TDD / BDD (Spec, Test, and Behavior-Driven Development):** Expressing clear developer intent to build and verify core logic.
* **CI/CD & DevOps:** Structuring automated integration, testing, security, and deployment pipelines.
* **Agile & Kanban:** Managing task flows and project tracking.
* **Product Development Loop:** Andrew Ng's three-loop framework for agentic software engineering: the *Agentic Coding Loop* (AI testing and iterating on code), the *Developer Feedback Loop* (developer directing visual design and specs), and the *External Feedback Loop* (using user feedback to iterate on the product vision).

To transition toward building in a truly AI-native way, father of DevOps - Patrick Debois has shared his thoughts in [The 4 Patterns of AI-Native Development](https://jedi.be/blog/2025/talk-2025-the-4-patterns-of-ai-native-development-ai-engineer-summit-edition/). It highlights four crucial shift patterns needed to build software in this new era:
1. **From Producer to Manager:** Shifting from manual line-by-line coding to reviewing and supervising AI outputs.
2. **From Implementation to Intent:** Moving from writing syntax to defining clear specifications and intent.
3. **From Delivery to Discovery:** Using rapid prototyping to explore ideas and discover constraints before writing production-grade code.
4. **From Data to Knowledge:** Structuring and capturing lessons, decisions, and architecture patterns during development.

### Deciding on Project #1: AI-Native Quant Trading

With these frameworks in mind, I've officially decided on my first indie startup project. 

I'm building an **AI-native quant trading platform** that allows users to backtest, deploy, and automate custom trading strategies. The first phase will be web-based.

This is a strictly one-person project, and I've set a tight deadline: build, test, and ship a working MVP to beta testers by the end of August. Having roughly a month to launch forces me to focus on speed and ignore low-value distractions.
